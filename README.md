# Disease Prediction Using Decision Tree

## Project Overview

Disease Prediction Using Decision Tree is a machine learning mini project that predicts diseases based on patient symptoms. The project uses a Decision Tree Classifier to analyze symptom patterns and identify the most probable disease. The goal is to demonstrate how machine learning can assist in healthcare by providing quick and accurate preliminary disease predictions.

## Features

- Disease prediction based on symptoms
- Data preprocessing and feature encoding
- Exploratory Data Analysis (EDA)
- Decision Tree model training and evaluation
- Performance measurement using accuracy and classification metrics
- Easy-to-understand and interpretable model

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow

1. Load and preprocess the disease dataset.
2. Perform exploratory data analysis to understand symptom patterns.
3. Encode categorical data and prepare features.
4. Split the dataset into training and testing sets.
5. Train the Decision Tree Classifier.
6. Evaluate model performance using accuracy, confusion matrix, and classification report.
7. Predict diseases based on user-input symptoms.

## Model Used

The project uses the Decision Tree Classification algorithm, which creates a tree-like structure of decisions based on symptom data. It is easy to interpret and provides effective classification results for disease prediction tasks.

## Results

The trained model successfully predicts diseases based on symptoms and achieves good classification performance on the test dataset. The model can be used as a basic healthcare support system for preliminary disease identification.
